# Audio Pimsleur

Unggah file MP3 ke folder ini dengan nama:

- `section3.mp3` — Seksi 3 (kosa kata)
- `section4.mp3` — Seksi 4 (analisis bahasa)
- `section5.mp3` — Seksi 5 (diskriminasi suara)
- `section6.mp3` — Seksi 6 (asosiasi sistem suara)

Path di app: `/audio/pimsleur/sectionN.mp3`

Sumber: folder audio Drive Pimsleur (seksi 3–6). Pastikan lisensi/izin penggunaan sudah clear sebelum produksi.
